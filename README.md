# CoreBank

Отказоустойчивый REST-сервис процессинга финансовых транзакций и межбанковских переводов, разработанный на **Spring Boot** и **PostgreSQL**.

Проект сфокусирован на решении ключевых проблем распределенных финансовых систем: предотвращении состояния гонки, исключении взаимных блокировок и обеспечении атомарности операций.

---

## Архитектурные решения и надежность

- **Пессимистические блокировки:** Использование `SELECT ... FOR UPDATE` на уровне PostgreSQL гарантирует изоляцию транзакций при одновременных списаниях и исключает возможность отрицательного баланса.
- **Предотвращение Deadlock:** При переводах между счетами блокировка строк в БД всегда выполняется в строгом порядке возрастания идентификаторов. Это математически исключает взаимную блокировку потоков при встречных переводах.
- **Атомарность операций:** Все этапы перевода выполняются в рамках единой ACID-транзакции. В случае сбоя гарантируется полный откат.
- **Финансовая точность:** Все денежные вычисления и комиссии реализованы через `BigDecimal` для исключения ошибок округления чисел с плавающей точкой.
- **Централизованная обработка ошибок:** Использование `@RestControllerAdvice` для формирования стандартизированных ответов API в случае бизнес-ошибок.

- **Тестирование:** JUnit 5, Spring Boot Test

## REST API Эндпоинты

| Метод | URL | Описание |
|---|---|---|
| `POST` | `/api/v1/accounts?userId={id}` | Открытие нового счета для пользователя |
| `GET` | `/api/v1/accounts/user/{userId}` | Получение списка всех счетов пользователя |
| `POST` | `/api/v1/accounts/{id}/deposit?amount={val}` | Пополнение счета |
| `POST` | `/api/v1/accounts/transfer?fromId={}&toId={}&amount={}` | Безопасный перевод между счетами |

## Тестирование многопоточности

В проект включен стресс-тест `AccountServiceTest`, симулирующий 20 параллельных встречных переводов между счетами через пул потоков `ExecutorService` и координацию `CountDownLatch`. Тест проверяет отсутствие взаимоблокировок и абсолютную консистентность суммарного баланса системы после завершения гонки потоков.

## Быстрый запуск

1. Склонировать репозиторий:
   ```bash
   git clone https://github.com/nastya29nik/core-bank.git
    ```
2. Запустить базу данных PostgreSQL в Docker:
   ```bash
   docker compose up -d
   ```
3. Запустить приложение:
   ```bash
   ./mvnw spring-boot:run
   ```
```
