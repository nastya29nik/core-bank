# CoreBank

Консольное банковское приложение, разработанное на чистом Spring Framework.

---

## Ключевые особенности

- **Чистый Spring:** Ручная настройка `ApplicationContext` и внедрения зависимостей.
- **Защита от Deadlock:** Алгоритм Lock Ordering исключает взаимные блокировки при параллельных встречных переводах.
- **Потокобезопасность:** Использование `synchronized` блоков и атомарных счетчиков `AtomicLong` в многопоточной среде.
- **Финансовая точность:** Все денежные операции реализованы строго через `BigDecimal` с защитой от отрицательных сумм и перерасхода.
- **Чистая архитектура:** Строгое разделение на слои `CLI` ➔ `Service` ➔ `Repository` ➔ `Entity`.

---

- **Язык:** Java 17

## Доступные команды
После запуска приложения в терминале будут доступны следующие команды:
- USER_CREATE — создание нового клиента банка.
- SHOW_ALL_USERS — вывод списка всех клиентов и их активных счетов.
- ACCOUNT_CREATE — открытие нового счета для пользователя (начисляется стартовый баланс по умолчанию из конфига).
- ACCOUNT_DEPOSIT — пополнение баланса счета.
- ACCOUNT_WITHDRAW — снятие средств со счета.
- ACCOUNT_TRANSFER — безопасный перевод средств между счетами (с учетом банковской комиссии для разных пользователей).
- ACCOUNT_CLOSE — закрытие счета с переводом остатка на другой активный счет пользователя.
- EXIT — завершение работы программы.
